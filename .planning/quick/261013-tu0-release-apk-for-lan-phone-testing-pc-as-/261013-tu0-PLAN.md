# Quick Task 261013-tu0: Release APK for LAN phone testing (PC as server)

<objective>
Build a release APK that runs on a physical Android phone and talks to the developer PC (LAN IP 192.168.10.93) for everything: the Express backend on :3000, the Firebase Auth emulator on :9099 and the Storage emulator on :9199.

Purpose: Two things currently break this. (1) `mobile/src/config/firebase.ts` connects the Auth/Storage emulators only when `__DEV__` is true. A release build has `__DEV__` false, so it would call real Firebase with 'fake-api-key' and fail. (2) Android 9+ release builds block cleartext HTTP. The backend and emulators are served over plain http://.

Output: an emulator opt-in flag in firebase.ts (documented in .env.example), expo-build-properties configured with android.usesCleartextTraffic, and a built, verified `app-release.apk`.
</objective>
