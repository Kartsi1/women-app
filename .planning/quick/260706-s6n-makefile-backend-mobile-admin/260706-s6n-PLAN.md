# Quick Task 260706-s6n: Makefile — единая команда запуска

## Goal

Одна команда поднимает всё приложение (backend + admin + mobile) в dev-режиме.
Zero-dep: только `make` + существующие npm-скрипты, без новых пакетов в корне.

## Context

Три независимых подпроекта, каждый со своим dev-сервером:

| Подпроект | Каталог   | Команда         | Порт / примечание          |
|-----------|-----------|-----------------|----------------------------|
| backend   | `backend/`| `npm run dev`   | Express :3000, нужен `.env`|
| admin     | `admin/`  | `npm run dev`   | Vite :5173                 |
| mobile    | `mobile/` | `npm start`     | Expo dev server (свой git) |

`mobile/` — отдельный git-репозиторий. Makefile его не коммитит и не трогает VCS,
только вызывает npm-скрипты по `cd`.

## Task 1 — Makefile в корне репо

**Files:** `Makefile` (new)

**Action:** Создать `Makefile` со следующими целями:
- `help` (default goal) — список команд.
- `install` — `npm install` последовательно в backend, admin, mobile.
- `dev` — параллельный запуск всех трёх dev-серверов в одной группе процессов;
  `trap 'kill 0' INT TERM EXIT` гарантирует завершение всех по Ctrl+C (без сирот).
  Пред-проверка: предупредить, если `backend/.env` отсутствует.
- `backend` / `admin` / `mobile` — по одному серверу.
- `.PHONY` на все цели (имена backend/admin/mobile совпадают с каталогами).

**Verify:**
- `make help` печатает список целей.
- `make -n dev` разворачивает рецепт с `trap 'kill 0'` и тремя фоновыми `npm`.
- `grep -q '^\.PHONY' Makefile`.

**Done:** Makefile существует, `make help` работает, `make dev` описан с корректным
завершением группы процессов.

## Must-haves

- truths:
  - "Одна команда `make dev` запускает backend + admin + mobile"
  - "Ctrl+C завершает все запущенные серверы (kill 0 на группу)"
  - "make install ставит зависимости во всех трёх подпроектах"
- artifacts:
  - `Makefile`
- key_links:
  - backend/package.json (script dev)
  - admin/package.json (script dev)
  - mobile/package.json (script start)
