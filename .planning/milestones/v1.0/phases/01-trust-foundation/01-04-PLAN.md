## Phase Goal

**As an** admin, **I want to** review each pending woman's ID document and selfie in a web panel and approve or reject her with a reason, **so that** only verified women are admitted and rejected applicants know why.

<objective>
Deliver the moderation vertical slice: a separate React+Vite admin web app (D-01/02/03) authenticated by hardcoded credentials (D-04), backed by admin endpoints that surface the pending queue with signed document URLs and drive approval (custom claim + push) and rejection (required reason + push).

Purpose: VERI-03 (admin review/approve/reject) and the backend half of VERI-04 (push send). Completes the trust decision that unlocks a user.
Output: A usable admin panel and the backend approval/rejection pipeline.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser → backend admin API | Session JWT crosses here; credentials checked against env |
| backend → Firebase Auth | Custom claim mutation is a privileged operation, admin-guarded |
| backend → Firebase Storage | Signed URLs expose documents for 15 min only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Elevation | admin credential brute-force | high | mitigate | short-lived (8h) session JWT; recommend express-rate-limit on POST /api/admin/login before production (RESEARCH Security Domain) |
| T-04-02 | Spoofing | forged admin session | high | mitigate | `verifyAdminSession` verifies JWT signature with ADMIN_JWT_SECRET and checks role=admin |
| T-04-03 | Elevation | unauthorized setCustomUserClaims | high | mitigate | approve/reject routes guarded by verifyAdminSession; claim set only by backend Admin SDK |
| T-04-04 | Information Disclosure | document exposure | high | mitigate | Storage rules deny public read; admin views via 15-min signed URLs only |
| T-04-05 | Tampering | reject without reason | medium | mitigate | backend 400s a reject with no reason; SPA disables Reject until reason present (D-07) |
| T-04-SC | Tampering | npm installs (vite, @vitejs/plugin-react) | medium | mitigate | Approved in RESEARCH Package Legitimacy Audit |
</threat_model>
