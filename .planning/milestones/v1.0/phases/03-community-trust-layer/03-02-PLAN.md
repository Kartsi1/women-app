| Boundary | Description |
|----------|-------------|
| mobile client → /api/posts/:id/like | Untrusted like toggle; potential counter-inflation abuse |
| mobile client → /api/posts/:id/comments | Untrusted comment body + injected authorUid |
| mobile client → report route | Untrusted report reason + injected reporterUid |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02-01 | Tampering | postController.toggleLike | medium | mitigate | Pre-check likedBy.includes(uid) before $addToSet/$inc so a repeated like never double-increments; held-out test asserts no drift |
| T-03-02-02 | Spoofing | commentController.createComment | high | mitigate | authorUid from req.user.uid, never req.body; held-out test asserts |
| T-03-02-03 | Elevation of Privilege | deletePost | high | mitigate | Delete allowed only for post author (or admin flag if reusable); non-owner gets 403/404 |
| T-03-02-04 | Elevation of Privilege | all comment/like routes | high | mitigate | verifyFirebaseToken + requireVerified on every route |
| T-03-02-05 | Tampering | Report reason | low | mitigate | reason required (existing Report validation); reporterUid + reportedUid set server-side |
| T-03-02-06 | Denial of Service | Comment.text | low | mitigate | schema maxlength 500 + non-empty trim validation |
